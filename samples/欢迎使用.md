# 欢迎使用墨流

InkFlow 墨流是一款为 Mac 打造的 Markdown 编辑器，追求**纸一般的质感**与**水一般的流畅**。

## 三分钟上手

1. **打开文档库**：`⌘⇧O` 选择一个文件夹，侧栏即刻变为你的文件树
2. **快速跳转**：`⌘P` 输入几个字母，模糊匹配库内任意文档
3. **专注写作**：`⇧⌘F` 专注模式淡化周围段落；`⇧⌘T` 打字机模式让当前行始终居中
4. **切换外观**：`⌘⇧P` 打开命令面板，输入"外观"，浅色 / 深色 / 跟随系统任选
5. **导出分享**：`⌥⌘P` 导出 PDF，或在文件菜单中导出 HTML

## 写作小贴士

- 直接 **粘贴截图**（`⌘V`），图片自动保存到 `assets/` 文件夹
- 把 `.md` 文件**拖进窗口**即可打开；把图片**拖进编辑器**即可插入
- 输入 `:` 触发 emoji 提示，例如 `:rocket` 🚀
- 输入 `[toc]` 自动生成目录；侧栏"大纲"页签实时同步标题结构
- 双击文件树中的文件可以**重命名**，右键有更多操作

## 常用快捷键

| 功能 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 | `⌘N` / `⌘O` / `⌘S` |
| 快速打开 / 命令面板 | `⌘P` / `⇧⌘P` |
| 加粗 / 斜体 / 行内代码 | `⌘B` / `⌘I` / `⌘E` |
| 侧边栏 / 大纲 | `⇧⌘L` / `⇧⌘J` |
| 专注 / 打字机 | `⇧⌘F` / `⇧⌘T` |

更多请按 `⌘/` 查看完整快捷键列表。
