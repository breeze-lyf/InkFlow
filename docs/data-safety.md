# 数据安全与恢复

墨流的原则是：磁盘文稿不被静默覆盖、临时恢复记录不冒充正式保存、失败必须对用户可见。

## 正常保存

- `savedValue` 保存 Vditor 规范化后的编辑器基线，用于判断页签是否变脏；`diskValue` 保存最近一次读取或写入的磁盘原文，用于写入前 CAS 比较。两者不能混用。
- 自动保存按页签独立调度，避免一个页签的计时器覆盖另一个页签。
- 文件写入与设置写入必须返回明确的成功或失败结果；失败时保留脏状态并显示提示。
- 文稿采用同目录临时文件、文件 `fsync`、原子替换和目录 `fsync`；设置与恢复 JSON 同样先持久化私有临时文件再替换，避免系统崩溃后只留下半次写入。
- 单篇文稿以 UTF-8 计最多 25 MiB；打开、写入和恢复都执行同一门禁。编辑器在越过上限的那次输入后立即回退到最后一个可恢复版本并提示，不会让用户继续编辑一份既不能保存也不能恢复的内容。
- 成功保存后更新基线并清理该页签的恢复草稿。

## 恢复草稿

- 未命名文稿和有路径但尚未成功保存的修改都会建立恢复草稿，按页签执行 600ms leading + trailing 节流，持续输入时不会让不同页签互相覆盖计时器。
- 恢复草稿保存在 Electron `userData/recovery.json`，键为 `untitled:*` 或 `file:<绝对路径>`，包含 `key/path/name/content/savedValue/diskValue/updatedAt`；存储使用临时文件替换，避免留下半截 JSON。
- 下次启动时只恢复仍有价值的内容；已经等同于磁盘内容的过期记录会清理。
- 单份草稿的正文、编辑器基线和磁盘基线各不超过 25 MiB，最多保留 64 份，恢复文件总量不超过 96 MiB；超限会明确失败，不能通过静默淘汰覆盖唯一恢复副本。普通设置存储默认限制为 8 MiB，发现超大旧文件时不会无界读取、解析或覆盖。
- 用户明确放弃、页签成功保存或恢复记录已无差异时清理；异常退出时保留。

恢复草稿是兜底，不是版本历史或备份。重要文稿仍应由用户自己的 Git、Time Machine 或云盘策略备份。

## 外部修改冲突

监听发现打开文稿变化后，先读取磁盘内容并与“当前编辑内容 + 已保存基线”三方比较：

- 本地无修改：接受磁盘版本并刷新页签。
- 磁盘无实质变化：保持当前编辑。
- 双方都变化或文件被删除：暂停该页签自动保存并显示内联冲突条；用户可选择“载入磁盘版”“当前内容另存为”或“明确覆盖”，删除场景可明确重新写回原位置。
- 写入前再次核对磁盘版本，覆盖动作必须来自用户的明确决定。

文档库 watcher 负责文件树增删改刷新；另有单文件 watcher 注册所有打开的可编辑文稿并在原子替换后重新挂载，因此从文档库外单独打开的文稿也进入同一冲突扫描。只读图片/PDF 预览不注册文稿 watcher。

## 本地资源边界

- 资源服务只绑定 `127.0.0.1` 的随机端口，并使用每次启动随机令牌路径。
- 只响应 `GET` / `HEAD`，只返回允许的媒体扩展名，不开放宽泛 CORS，并设置 `nosniff` 与 `no-referrer`。
- 路径能力默认拒绝，只能来自系统对话框、Finder `open-file`、已持久化且仍有效的 session/recent/recovery、真实 `File` 拖放或内置 samples；文件动作继续细分 `read/write/asset` 能力。
- 授权路径使用 realpath 或最近存在祖先规范化，阻断 `..`、普通符号链接与悬空符号链接逃出目录边界；磁盘根目录和 UNC 根目录使用相对路径关系判定，不依赖易出错的字符串前缀。请求路径必须位于文档库、已打开文稿相邻资源目录，或由系统选择/拖放显式授予的路径内。
- 页面不能借资源服务读取任意绝对路径；服务关闭时令牌随进程失效。

导出前会移除脚本、可执行嵌入元素与内联事件处理器，阻断 `javascript:` 等主动 URL scheme，并转义文稿元数据。任务列表的表单控件不会被带入产物，而是固化为不可执行的 `☑` / `☐` 文本，保留完成状态。新增导出格式或 HTML 模板时必须继续经过同一净化边界。

导出还执行输入预算与图片结构验证：远程图片不自动下载，本地图片必须位于已授权范围内；只接受 PNG/JPEG/GIF/WebP/BMP，限制单图大小、图片数量、总字节和像素尺寸。SVG 先由主进程按元素、属性、IRI 与 CSS 白名单净化，再在隔离渲染窗口中栅格化。Word 使用更严格的格式专属预算，并在可超时终止、限制堆内存的独立 utility process 中转换，转换库不会阻塞 Electron 主进程。PDF/PNG 与 Word 使用的中间文件位于权限为 `0700` 的随机临时目录，文件权限为 `0600`，导出结束即清理。

安全问题复核时，同时检查 preload 白名单、主进程参数验证、路径授权和资源服务，不能只看其中一层。

主窗口与临时导出窗口均启用 Electron sandbox、context isolation 并关闭 renderer Node 集成；所有 IPC handler 还会核对来源 `webContents`。这些是互补防线，不能用其中一项替代其他项。
