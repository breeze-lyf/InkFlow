## 2. V2EX

**配图**：`twitter-card-1600x900.png`（贴正文顶部）

**标题**：
```
[开源] InkFlow 墨流：一个 macOS 上的 Markdown 编辑器
```

**正文**：
```
做这个东西的原因很简单：Typora 收费，VSCode 写文档不顺手，想要的组合没人做，就自己写了。

功能上对标 Typora 的写感，敲符号直接渲染，没有预览栏。在这之上加了文档管理：打开一个文件夹就是工作台，文件树、多页签、大纲导航。点文件树里的图片和 PDF 可以直接预览，截图粘贴自动存盘。

导出做得比较细：PDF、Word、2 倍分辨率的长图。Mermaid 流程图导出时会渲染成图形，不是代码块。

技术栈 Electron + Vditor，MIT 协议。有 36 项自动化回归测试，日常自己在用，更新频率还可以。

两点说明：

1. 没有 Apple 公证，首次打开会提示"已损坏"。DMG 里放了一个双击解除的脚本，或者终端 xattr 一条命令。不放心可以拉源码自己构建。
2. 目前只有 Apple Silicon 版本。Win/Linux 的构建配置是现成的，有需求就发。

官网：https://inkflow.yufeng.fun
GitHub：https://github.com/breeze-lyf/InkFlow

试用反馈和 issue 都欢迎。
```
